# meysammahboudi.github.io

Personal website of Meysam Mahboudi — bilingual (English default, Persian at /fa/), built with Jekyll for GitHub Pages.

- Text for home + CV: `_data/cv.yml`
- Interface text: `_data/i18n.yml`
- Settings (emails, CV PDF): `_config.yml`
- New post: add `_posts/YYYY-MM-DD-slug.md` with `title` and `lang` (en/fa) in the front matter.

Full guide in Persian: `راهنما.md`
